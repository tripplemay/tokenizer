为什么用 Tokenizer

多设备聚合

一个账号关联多台机器，每台设备一个 token，数据汇总到同一仪表盘。

多项目过滤

按工作目录自动归类项目；可一键过滤"只看 Git 项目"，屏蔽实验性目录。

时间窗切换

后台自动同步

安装后即装即用：后台 agent 默认每 15 分钟采集并上传一次，每 60 秒心跳上报状态；幂等去重，重跑安全。

60 秒上手

三步把这台机器接进来

不用装 CLI、不用改环境变量。控制台一键签发一条安装命令，粘到终端就行。

  1. 1

    在控制台生成安装命令

    登录 dashboard → 点击「生成安装命令」。服务器会签发一条 30 分钟内有效的一次性安装命令，包含你的 enroll token 与服务地址。

  2. 2

    粘贴到 Mac / Linux / WSL 终端

    命令长这样（具体内容由控制台生成，无需手填）：自动检测 Node、克隆 agent、注册本机、安装后台同步服务。

    curl -fsSL https://<your-server>/install.sh | bash -s -- \
  --enroll-token <token> --server-url https://<your-server>
  3. 3

    等待首次同步（约 60–90 秒）

    客户端首次上线后，控制台会自动显示「已连接：<设备名>」，dashboard 数据无需刷新就会出现。后续每 15 分钟自动同步一次。
